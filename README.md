# Michael Cretu

Artist site for Michael Cretu — composer, solo double bassist, and musical director of the Manchester International Roots Orchestra. Built with Next.js for GitHub and Vercel.

```bash
npm install
npm run dev
```

Optional environment variables:

- `NEXT_PUBLIC_SITE_URL` — public site URL (used for metadata and sitemap)
- `NEXT_PUBLIC_CONTACT_EMAIL` — booking address for the contact form
